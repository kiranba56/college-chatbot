100% Flask Native Backend Architecture

This campus chatbot is powered natively by Flask and local embedded SQLite:

  • Standalone Flask Server: No external Supabase or cloud setup required.
  • Persistent Local Storage: College knowledge, chat logs, and student ratings are saved in data/college_chatbot.db.
  • High-Speed Vector Engine: Semantic search and cosine similarity are computed directly within Flask.
  • Gemini AI: Optional Gemini API key in .env provides neural response generation.
